## Instruction to Codex
Read the complete GDD and inspect the supplied image before implementation.

Start with **Stage A: one art-direction proof** showing a coherent republic overview and representative mini-game visual direction. Do not start full production before the user approves the proof.

After approval, implement the full game autonomously, with automated tests and bounded QA. Preserve five genuinely playable mini-games, 80% milestone checks, Town Hall's passive debate, EN/zh-TW, and the deliberately unresolved ending.

Do not use a concept image as a substitute for interactive game rendering. Do not publish a public website without user authorization.

The GDD distinguishes locked creative decisions from implementation defaults. Where details are delegated, choose sensible solutions without repeatedly requesting decisions.
